# SAMPLE-CREATE-REPOSITORY
Aim: To set up a Git repository for a Data Science project and push it to GitHub for version control. Step 1: Create a project folder mkdir data-science-project cd data-science-project Step 2: Initialize Git repository git init Step 3: Create project files echo "# Data Science Project" &gt; README.md echo "numpy pandas matplotlib scikit-learn" &gt; requirements.txt Step 4: Check repository status git status Step 5: Add files to Git git add . Step 6: Commit changes git commit -m "Initial commit" Step 7: Create repository on GitHub GitHub → New Repository → Enter repository name → Create Repository → Copy URL Step 8: Connect local repository to GitHub git branch -M main git remote add origin https://github.com/&lt;username&gt;/data-science-project.git Step 9: Push project to GitHub git push -u origin main Step 10: Verify repository Open the GitHub repository and check README.md and requirements.txt. Result: The project is initialized as a Git repository and pushed to GitHub.
